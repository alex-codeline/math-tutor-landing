# Сайт репетитора математики — учебный проект

Адаптивный одностраничный сайт (landing page) для **вымышленного** репетитора Марии Лебедевой.
Проект сделан для практики вёрстки и как работа в портфолио начинающего веб-разработчика.

> **Важно.** Мария, её биография, цены, условия занятий и тексты придуманы для учебного проекта.
> Отзывов, дипломов, стажа и результатов учеников на сайте нет намеренно: выдумывать их нельзя.
> Форма обратной связи работает в **демонстрационном режиме** — данные никуда не отправляются и не сохраняются.

## Какую задачу решает сайт

Родитель, который ищет репетитора, должен за пару минут понять:
кто занимается с учеником, с какими задачами можно прийти, как проходят занятия,
сколько они стоят и как задать вопрос.

## Технологии

- **HTML5** — семантическая разметка (`header`, `main`, `section`, `article`, `details`, `form`).
- **CSS3** — переменные, Flexbox, CSS Grid, `clamp()`, медиазапросы (точки 980 px и 700 px).
- **JavaScript** (без библиотек) — мобильное меню, подсветка активного раздела, проверка формы.

Внешние шрифты, фреймворки и картинки не используются: сайт состоит из трёх файлов.

## Что реализовано

- Адаптивная вёрстка: от 320 px до широких мониторов, без горизонтальной прокрутки.
- Мобильное меню с кнопкой, закрытием по `Esc` и по выбору пункта.
- Подсветка раздела, который сейчас на экране.
- Проверка формы на русском языке: ошибки под полями, переход к первому неверному полю.
- Доступность: ссылка «Перейти к содержимому», видимый фокус, подписи у всех полей, `aria`-атрибуты.
- Уважение к настройке системы «уменьшить анимацию» (`prefers-reduced-motion`).
- Без JavaScript сайт остаётся читаемым: меню превращается в обычный список ссылок.

## Как запустить локально

1. Скачайте или клонируйте репозиторий.
2. Откройте файл `index.html` в браузере (двойной щелчок) — этого достаточно.
3. Удобный вариант для разработки: в VS Code установите расширение **Live Server**,
   нажмите правой кнопкой на `index.html` → **Open with Live Server**. Страница будет обновляться при сохранении файлов.

## Как опубликовать на GitHub Pages

1. Создайте на GitHub репозиторий, например `math-tutor-landing`, и загрузите в него файлы проекта.
2. Откройте **Settings → Pages**.
3. В разделе публикации выберите развёртывание из ветки `main` и корневой папки (`/root`).
4. Сохраните настройки и дождитесь публикации.
5. Проверьте полученную ссылку в браузере и на телефоне.

Адрес обычно выглядит так: `https://ВАШ-ЛОГИН.github.io/math-tutor-landing/`.
Точные названия пунктов могут измениться — сверяйтесь с официальной документацией GitHub Pages.

## Что нужно заменить, если делать сайт для реального человека

- Имя, тексты и цены — на согласованные с исполнителем.
- Контакты: добавьте реальные ссылки (Telegram, почта, телефон) в раздел «Контакты».
- Форма: сейчас она только показывает сообщение. Для реальных заявок нужен обработчик —
  сервис приёма форм или собственный сервер. Проверка в браузере удобна, но не заменяет проверку на сервере.
  Также потребуется согласие на обработку персональных данных и защита от спама.
- Фотографии — только собственные или с подходящей лицензией.
